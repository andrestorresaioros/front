# Four Card Feature Section

Reto de maquetación frontend resuelto con HTML y CSS a partir de un diseño y una guía de estilos (desafío de [Frontend Mentor](https://www.frontendmentor.io/)).

## Contenido

- `index.html` — estructura de la página
- `styles.css` — estilos de la sección
- `design/` — capturas de referencia del diseño (móvil y escritorio)
- `images/` — recursos gráficos utilizados
- `style-guide.md` — paleta de colores y tipografías del diseño original

## Ejecución

Abrir `index.html` directamente en el navegador, o servir la carpeta:

```bash
python -m http.server 8000
```

Luego abrir `http://localhost:8000`.
